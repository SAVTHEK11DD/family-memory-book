# Family Memory Book

A single-page digital memory book built to document a year of friendship and fellowship.

## Built With
- HTML
- CSS
- Vanilla JavaScript

## Live Site
https://family-memory-book-by-sav.netlify.app

## About
I've been learning HTML, CSS, and JS and wanted to build something real.
This is a gift for a family I met through church — a way to preserve
the memories, milestones, and moments of our first year together.
